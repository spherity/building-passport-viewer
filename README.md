# Agentic Building Passport Viewer (concept demonstration)

A connected passport viewer for a fictional single-family home in Germany: home scene, hierarchy and knowledge graph views, alerts, registrations, grid operator view, flex service selection and an About page on the concept.

- All parties and values are fictional or labelled illustrative. Specimen certificates carry no number and are not issued.
- The dashboard is generated from the same specification as 13 demonstration product passports on the VERA staging platform. It does not read the passports live.
- The About page separates what is established (standards, law, with sources) from what is a concept of the authors.
- Real provider names on the flex selection are text only, in a fictional demonstration ordering. They are not an assessment.

This repository holds the built static site only. Open `index.html` locally or publish with GitHub Pages (Settings > Pages > Source: GitHub Actions).

## Other demos

- `BESS-demo.html`: a fictional BESS container as a connected passport system.
- `AgriPV-demo.html`: an agrivoltaic plant as a connected passport system.
- `ROBOT-demo.html`: MiPA, a mobile dual-arm service robot, on a fictional hospital ward as a verifiable assurance graph: parts, skills and three use cases linked to regulations, registers, standards, certificates, test reports and prepared filings. Based on public specifications in NEURA's call for proposals; not provided, reviewed or endorsed by NEURA Robotics. All other parties, values, certificates and statuses are examples.
